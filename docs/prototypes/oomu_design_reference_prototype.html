🏛️ 한국 모임 앱 5종 관찰 사실 vs OOMU 재해석 기준표

공식 웹 및 공개 디자인 시스템 문서를 통해 직접 검증한 내용과, OOMU 시스템에 적용한 초기 제안 기준을 투명하게 분리하여 기록했습니다.

레퍼런스 검증 출처 실제 관찰 사실 (Facts) OOMU 재해석 및 적용 기준 (Proposal)
문토 (Munto) 공개 웹 화면
munto.kr		 • 소셜링/클럽/챌린지처럼 목적을 명확히 구분하는 탐색 구조.
• 밝은 바탕에 사진과 제목 중심으로 모임 분위기를 전달.
• (한계) 공개 웹 상단에 기획 배너와 다수의 카테고리가 배치되어 정보량이 과밀함. 		• 목적 분리 채택: ⚡ 오늘 번개(즉석), ☕ 취향 아지트(취미), 🏃‍♂️ 라이프 메이트(생활) 3대 탭 유지.
• 과밀 배제: 다단 기획 배너와 과도한 카테고리 확장을 지양하고, 모임 피드를 첫 화면 상단에 배치.
프립 (Frip) 공개 상품 웹
frip.co.kr		 • 카드 안에서 사진 → 지역 → 제목 → 후기 → 가격 순서로 명확한 정보 위계를 가짐.
• 카드 전체를 두꺼운 보더로 감싸기보다 사진과 텍스트 정렬로 단정하게 그룹핑.
• (한계) 할인율·쿠폰·긴 홍보 문구가 카드를 복잡하게 만듦. 		• 위계 채택: 카드 순서를 사진 ➔ 제목 ➔ 일정/장소 ➔ 주최자 ➔ 참여인원으로 통일.
• 정산 투명성: 원화 가격 대신 1/N 안심 정산 또는 무료 참여 표기로 변경하여 영리성 커머스 분위기 차단.
당근 SEED 공식 디자인 시스템
seed-design.io		 • 좌우 여백 16px, 칩 간격 8px 등 역할별 토큰 체계 정립.
• 글자 크기와 줄 높이(line-height), 글자 두께(weight)를 일체로 정의하여 줄바꿈 안정성 확보.
• 주 액션과 보조 액션의 시각적 무게를 명확히 분리. 		• 간격 토큰 적용: 좌우 16~20px, 카드 내부 16px, 정보 간 6~8px, 섹션 간 24~32px 출발점 채택.
• 터치 영역: 가시 크기(16px)와 인터랙션 영역(최소 48×48px) 분리.
• 지도 진입 버튼을 얌전한 보조 버튼으로 변경.
소모임 (Somoim) 스토어 및 도움말
somoim.co.kr		 • 취미와 지역을 통해 모임을 찾고 오프라인 정모에 참여하는 기본 과업 구조 확인.
• *주의: 네이티브 앱 내부 화면의 상세 수치를 직접 측정한 것은 아님. 		• 과업 참고: 동네 설정과 관심사 기반 정모 참여라는 필수 유저 저니만 보조적으로 참고하고 무리한 클론 지양.
위피 (Wippy) 스토어 안내

• *주의: 네이티브 내부 인터랙션을 직접 추출한 것은 아님. 		• 대화 진입점 참고: 프로필의 관심사 칩과 취향 문답을 자연스러운 대화 진입점으로 활용하되, 외모/스펙 평가 중심의 데이팅 요소는 배제.

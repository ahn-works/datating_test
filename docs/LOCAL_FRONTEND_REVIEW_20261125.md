## 화면 대조 결과

1. **로그인**: 로컬과 공개 화면의 배치와 버튼 구성이 같았다. 새 계정 가입 절차는 완료하지 못했다.
2. **지도 탐색**: 공개 화면은 여수 고정 중심, 여러 모임의 동일 좌표 및 `도보 0m`를 표시했다. 로컬은 위치 선택 전 지도를 비워 두고 `위치 확인 전`, `거리 확인 불가`를 표시한다. 좌표가 확인되지 않은 자동 모임은 마커와 `지도 선택됨` 표시를 하지 않는다.
3. **장소 검색**: 로컬에서 `여수 학동` 검색 결과가 없었다. 결과가 없을 때 `네이버 지도 검색` 버튼을 제공한다. 현재 데이터와 고정 백엔드만으로 앱 안에서 전국 장소 검색을 완료할 수는 없다.
4. **코노 모임 상세**: 로컬 목록과 상세에서 장소 이름은 같지만, 목록의 매너온도 `41.8°C`와 상세의 `43.5°C`가 다르다. 코노 모임에 와인 모임 사진이 노출된다. 공개 화면은 다른 코노 모임에 러닝 사진이 노출된다. 두 환경의 코노 모임은 서로 다른 문서라서 1:1 전후 비교는 아니다.
5. **지도 렌더링**: 공개 사이트의 네이버 지도 타일과 마커는 잠시 후 로드됐다. 로컬 상세의 네이버 지도 iframe은 `네이버 지도를 불러오지 못했어요`를 표시했다. localhost 허용 도메인 또는 클라이언트 키 설정 여부는 확인이 필요하다. 로컬 지도 렌더링 성공은 검증되지 않았다.

## 수정 내용

- 서버 함수, GitHub Actions 워크플로, 크롤러의 이번 작업 변경은 작업 전 백업으로 복원했다. GitHub 업로드와 배포는 하지 않았다.
- 지도 탐색의 임의 기본 위치, 도보 거리 추정, 고정 지도 모임/핫스팟을 제거했다. 실제 좌표가 있는 모임만 마커로 제공하고, 좌표가 없는 모임도 목록과 상세 진입은 유지했다.
- 장소 검색은 기존 서버에 없는 새 API를 호출하지 않게 했고, 확인된 네이버 장소 데이터가 없으면 외부 네이버 지도 검색을 안내한다.
- 모임 개설은 장소 좌표를 확인하지 못해도 진행할 수 있게 했다. 이때 지도와 거리가 표시되지 않는다고 입력 화면에 알린다.
- 모임 승인 성공 때만 채팅방으로 이동하도록 했고, 채팅 중간 지점의 잘못된 좌표 키와 임의 기본 출발지를 정리했다.

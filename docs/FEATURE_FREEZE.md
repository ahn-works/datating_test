# 고정된 기능 목록 (Feature Freeze)

A~Z 풀스택 검사를 100% 통과해 **더 이상 건드리지 않는** 기능 목록이다.
기준과 절차: [`docs/OOMU_풀스택_검사기준.md`](OOMU_풀스택_검사기준.md) 5장.

- 고정한 기능의 파일은 [`scripts/feature_freeze.json`](../scripts/feature_freeze.json)에도 적는다. Branch CI가 그 파일이 바뀐 push를 실패시킨다.
- 고쳐야 할 때는 **대표님 승인 → 커밋 메시지에 `[freeze-unlock: 기능 이름]` → 수정 → 다시 A~Z 검사 → 다시 고정** 순서로 한다.
- 승인 없이 해제 표시를 넣거나 목록에서 지우지 않는다.

| 기능 | 고정일 | 고정 커밋 | 검사보고서 | 지키는 자동 테스트 | 비고 |
| --- | --- | --- | --- | --- | --- |
| (아직 없음) | | | | | 첫 후보: 모임 생성 A~Z |

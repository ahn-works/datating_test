# OOMU 풀스택 검사 기준

모든 검수(사람·에이전트·매일 예약 검수)는 이 문서대로 한다.
결과는 `docs/reports/검사보고서_YYYYMMDD.md`로 남긴다 (양식은 맨 아래).

---

## 0. 판정 규칙

각 기능을 **4칸**으로 따로 판정한다. 4칸 모두 통과해야 그 기능이 "완료".

| 칸 | 무엇을 보나 | 어떻게 확인하나 |
|---|---|---|
| **화면** (프론트엔드) | 버튼을 누르면 실제로 동작하나, 결과가 화면에 보이나, 오류 시 안내가 나오나 | 테스트 계정으로 직접 조작 + 캡처 |
| **데이터** | Firestore·R2에 맞는 값이 저장되나, 새로고침·재로그인 후에도 남아 있나, 다른 화면과 같은 값인가 | 조작 전후 DB 문서·R2 주소 대조 |
| **백엔드** | 서버·보안 규칙이 허용할 것만 허용하나 (남의 글 수정, 비로그인 접근 거부) | 다른 계정·비로그인으로 시도 |
| **디자인** | 글자 잘림, 색 번짐, 겹침, 1~2글자 줄바꿈, 터치 영역 48px, 빈 상태·로딩 | 360/390/430px + 글자 크게 캡처 |

판정 값: **통과** / **실패**(증상 적기) / **미검증**(못 본 이유 적기). 미검증은 0점.
"코드상 될 것 같다"는 통과가 아니다. 반드시 화면이나 데이터로 확인한다.

테스트 계정: A(기본), B(A와 같은 동네), C(다른 동네). 대표님이 발급.

## 2. 공통 디자인 검사 (모든 화면)
- 360 / 390 / 430px 폭, 글자 크게 설정에서 캡처
- 글자 잘림·겹침·1~2글자 줄바꿈 0건, 가로 스크롤 0건
- 색: 배경 #F7F8FA, 카드 흰색, 코랄은 주요 버튼·선택 탭·하트·안 읽음 점에만
- 이모지는 사용자가 쓴 글 안에서만, 장식 이모지·네온 그라데이션 금지
- 로딩은 회색 스켈레톤, 빈 상태는 "아이콘 + 한 줄 + 버튼 1개"
- 터치 영역 48×48 이상, 입력창 높이 48 이상

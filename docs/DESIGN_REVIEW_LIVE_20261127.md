## 잘 된 것 (실측)

- 로그인 화면: 요소 정렬, 입력칸 높이(52), 소셜 버튼 위계가 깔끔하다
- 채팅 빈 상태: 아이콘 + 한 줄 + 버튼 1개 규칙을 지킨다
- 하단 탭: 활성 탭이 검정 굵은 글씨로 구분되고 높이가 안정적이다
- 모임 상세: 하단 고정 CTA가 코랄 하나뿐이고, 찜 버튼은 보조 스타일이다
- 이미지 실패 시 회색 박스와 사진 아이콘으로 대체되고, 엑박은 나오지 않는다

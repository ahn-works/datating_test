OOMU의 docs/OOMU_UI_GUIDE.md와 docs/UI_PROGRESS.md를 읽고 5단계만 진행해줘. 보안 전용 파일은 읽거나 수정하지 마. 상세·홈에서 채택한 공통 디자인을 유지해줘.

프로필을 먼저 수정·검증한 다음 커뮤니티로 이동해줘. 여러 화면을 동시에 크게 수정하지 마.

프로필:
1. 실제 연결된 my_page_screen.dart와 profile_edit_screen.dart의 현재 사용 경로를 확인해줘. 이름이 비슷한 미사용 화면을 대신 수정하지 마.
2. 프로필 확인·사진 관리·소개·관심사·수정 행동이 명확한 순서로 보이게 해줘. 아바타와 대표사진의 중복 표현, 멤버십 배너의 과도한 시각적 비중을 조정하되 기존 기능은 유지해줘.
3. 입력창 높이·라벨·도움말·오류 표시·저장 중·취소 상태를 공통 기준에 맞춰줘. 키보드가 올라온 상태와 긴 소개·큰 글자에서도 확인해줘.

커뮤니티:
4. 실제 연결된 목록·community_post_detail_screen.dart·community_post_create_screen.dart에 같은 글자·여백·아이콘 기준을 적용해줘.
5. 작성자·본문·사진·댓글·좋아요 순서와 메타정보의 강조를 구분해줘. 모든 구간을 별도 카드와 두꺼운 테두리로 둘러싸지 마.
6. 댓글 입력창·작성 버튼·보조 액션의 크기와 정렬을 통일해줘. 긴 한국어·키보드·빈 상태·기존 오류 상태를 현재 구현 범위에서 검수해줘.

저장·댓글·좋아요·인증 로직과 운영 데이터는 변경하지 마. 조작 검증은 승인된 개발용 데이터가 있을 때만 수행하고, 없으면 입력·표시·키보드 검수까지만 한 뒤 실제 저장은 미검증으로 기록해줘.
각 흐름에서 실제 현재 코드의 전후 화면·관련 검사 결과를 남겨줘. 보안·환경변수·git·배포는 변경하지 말고, 새 매칭·안심귀가 기능은 다음 과제로 기록해줘. 여기서 끝내줘.

OOMU의 docs/OOMU_UI_GUIDE.md와 docs/UI_PROGRESS.md를 읽고 4단계만 진행해줘. 보안 전용 파일은 읽거나 수정하지 마. 직전 단계의 실제 상세 화면 결과를 유지하고 새 색상·새 폰트·새 스타일을 만들지 마.

이번 수정 대상은 main.dart에서 실제 연결된 soso_car_home_screen.dart와 필요한 공통 모임 카드뿐이다. 연결되지 않은 home_screen.dart를 대신 수정하지 마.

1. 수정 전 홈 화면과 작업 상태를 확인하고, 초기 백업이 아닌 현재 변경 내용을 보존하는 체크포인트도 남겨줘.
2. 첫 화면에서 동네·핵심 필터·참여할 모임을 쉽게 찾도록 정보 순서를 조정해줘. 행사 큐레이션이 모임 탐색 전체를 밀어내지 않도록 비중을 줄이고, 기존 기능은 찾을 수 있는 위치에 유지해줘.
3. 지도 배너·접속 문구·LIVE·칩·도트·이모지가 동시에 강조되는 상황을 줄여줘. 확인 가능한 상태와 직접 관계없는 홍보 문구를 시각적 강조의 근거로 사용하지 마.
4. 모임 카드를 사진·제목·일정/장소·참여 정보·주최자 순서의 공통 구성으로 정리해줘. 목록형과 블록형도 같은 데이터·타이포그래피·상태 표현을 사용하게 해줘.
5. 읽기 어려운 긴 제목을 대칭 2열에 억지로 넣지 마. 콘텐츠에 맞는 행 구성을 사용하고, 수평 스크롤 가능성을 암시하는 일부 노출과 실제 텍스트 잘림을 구분해줘.
6. 제목·본문·메타 정보의 굵기와 대비를 구분하고, 배지 수·그림자·테두리를 절제해줘. 지도 진입 버튼은 주요 참여 행동과 시각적 무게를 구분해줘.
7. 필터·보기 전환·상세 진입·뒤로가기·스크롤 위치를 실제로 확인하고, 현재 로컬 코드에서 360/390/430 폭의 전후 화면을 남겨줘.

데이터 쿼리·카테고리 정책·DB 구조·신청·인증·보안·git·배포는 변경하지 마. 필요한 최소 위젯 분리만 하고 전체 파일 구조 개편은 하지 마. 수정·검증·남은 문제를 기록하고 여기서 끝내줘.

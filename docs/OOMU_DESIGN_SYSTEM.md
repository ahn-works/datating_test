# OOMU 디자인 시스템 (단일 기준)

> 앱의 모든 UI 수치는 이 문서가 유일한 기준입니다. 다른 문서·규칙·스킬은 이 문서를 가리키기만 하며 수치를 따로 적지 않습니다.
> 코드 쪽 단일 원천: `lib/ui/oomu_tokens.dart`, `lib/ui/oomu_theme.dart`

## 1. 색

| 역할 | 값 |
| --- | --- |
| 배경 (전 화면 동일) | `#F7F8FA` |
| 카드·시트·앱바 | `#FFFFFF` |
| 보조면(칩·검색바) | `#F2F4F7` |
| 선 | `#EAECF0` |
| 글자 · 제목 | `#191F28` |
| 글자 · 본문 | `#333D4B` |
| 글자 · 보조 | `#6B7684` |
| 글자 · 흐림 (힌트·비활성에만) | `#8B95A1` |
| 코랄 (채움) | `#F25767` |
| 코랄 (작은 글씨) | `#D9384A` |
| 오류 | `#E11D48` |
| 인증 완료 | 틸 1종 `#0D9488` (인증 표시에만) |

- 코랄 사용처: **화면당 주요 버튼 1개, 선택된 탭, 좋아요 하트, 안 읽음 점**. 그 외 금지.
- 주황·남색·노랑·보라 금지. 배경에 분홍기 금지.

## 2. 글자

- 서체: Pretendard (번들), 굵기 400 / 600 / 700.
- 크기: **11, 12, 14, 16, 18, 22** (스플래시 28만 예외). 11 미만 금지.

## 3. 모서리·간격·깊이

- 모서리: 8(작은 이미지·태그) · 12(버튼·입력) · 16(카드) · 24(바텀시트) · 알약.
- 간격: 4 · 8 · 12 · 16 · 20 · 24 · 32. 좌우 여백 20, 카드 안 16, 카드 사이 12, 섹션 사이 32.
- 카드는 그림자 없이 1px 선. 그림자는 바텀시트·플로팅 버튼만. 그라데이션은 사진 위 가독성 스크림만. 박스 안 박스 금지.

## 4. 아이콘·터치·상태

- 아이콘은 Material 아이콘 한 세트(Rounded). 이모지는 사용자가 쓴 제목·본문 안에서만.
- 누를 곳은 48×48 이상.
- 로딩은 스켈레톤(회색 블록). 빈 상태·오류는 "아이콘 + 한 줄 + 버튼 1개".
- 배지: 사진 위 최대 2개, 카드 하나에 강조 배지 1종.

## 5. 공통 부품 (`lib/ui/`, 2단계에서 구현)

OomuButton, OomuChip, OomuTag, OomuBadge, OomuMeetupCard(block/list), OomuSectionHeader, OomuInfoRow, OomuAvatar, OomuEmptyState, OomuSkeleton, OomuSheet, OomuAppBar.

## 6. 작업 규칙

- 화면 파일에 `Color(0x..)`, 글자 크기 숫자, `BorderRadius.circular(숫자)`를 새로 쓰지 않는다(토큰만). 점검: `python scripts/check_design_tokens.py`.
- 보안 지침(`.antigravity/rules/security_distribution_rules.md`, `docs/SECURITY_AGENT_GUIDE.md`)은 이 문서와 무관하게 수정하지 않는다.
- 보고에 "완벽", "무결점" 같은 표현을 쓰지 않는다.

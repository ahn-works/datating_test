## 2. 단계별 계획

### 2단계 — 기능 전수 검사·수정 (12/5 ~ 12/11)
검사 기준서 기능 1~26번을 테스트 계정 A·B·C로 하나씩 검사하고, 실패한 것을 고친다.
특히 먼저 볼 것:
- 사진: 프로필·글·채팅 사진 올리고 새로고침 → 그대로 있나, R2 주소인가
- 동기화: 닉네임·사진·나이·성별 바꾸면 글·댓글·채팅·모임 호스트 표시가 같이 바뀌나 (현재 **안 바뀌는 구조**로 확인됨)
- 지도: 모임 개설·상세에서 네이버 지도 표시, 내 위치→모임 장소 거리
- 모임 신청·승인: 현재 비활성 상태로 기록됨 → 실제 동작하게
- 좋아요·댓글 수: A가 누르면 B 화면 숫자도 같나
